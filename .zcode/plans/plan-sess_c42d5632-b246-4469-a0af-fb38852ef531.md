## Mục tiêu (Đợt 1 — Theme sync theo portfolio)

Đồng bộ giao diện Chakra RAG theo palette "developer-portfolio" của `/home/roser/Work-Code/portfolio`: **Light + Dark mode** (mặc định dark như portfolio), font Geist + Geist Mono, accent teal-green `#267A66 ↔ #9BCEC1`, nền `#F8FAF9 ↔ #070A0A`, sidebar không còn "luôn tối" mà đổi theo theme. Giữ nguyên toàn bộ chức năng hiện tại (upload, ingest, chat, citations, drawer, inspector).

Phạm vi **chỉ theme** — các cải tiến UI/UX còn lại (gợi ý câu hỏi, stop generating, phím tắt, rename…) để đợt sau.

## Thay đổi file

### 1. `ui/index.html` (sửa)
- Thêm inline script chống FOUC: đọc `localStorage["chakra-theme"]` (mặc định `"dark"`), set `class="dark"`/`light` lên `<html>` trước khi render.
- Thêm `<meta name="color-scheme" content="dark light">`.
- Thêm Google Fonts: Geist + Geist Mono (fallback system nếu offline).

### 2. `ui/src/hooks/useTheme.ts` (tạo mới)
- Hook đọc/ghi `chakra-theme` trong localStorage, bật/tắt class `.dark` trên `document.documentElement`, trả về `{ theme, toggle }`. Kiểu nhẹ, theo cấu trúc `hooks/` sẵn có.

### 3. `ui/src/components/theme/ThemeToggle.tsx` (tạo mới)
- Nút toggle ☾/☀ dùng `useTheme`, đặt trong sidebar. Style bằng class CSS mới (`theme-toggle`).

### 4. `ui/src/app/styles.css` (sửa lớn)
- Chuyển `:root` sang light palette + thêm block `html.dark`.
- Remap toàn bộ màu hardcode còn lại sang token để cả 2 mode đều đúng:
  - `#fff` trên nền accent → `var(--accent-contrast)` (brand-logo, empty-logo, avatar, source-num, new-chat-btn, send-btn).
  - `#fff` / `#fafafa` nền card (composer, drawer, doc-list-pane, doc-chunk-item, doc-tabs, doc-detail-pane, doc-full-pane, tool-result-chip) → `var(--bg-card)`.
  - Hover `#efefef` / `#e8e8ec` → `var(--bg-elevated)`.
  - Màu chữ accent cũ `#0d7a5f` (cite-chip, answer-text a, tool-result-chip) → `var(--accent)`.
  - Viền `#d9d9de` (thinking-block, blockquote, spinner) → `var(--border)`.
  - Warning/error badge + error-banner: thêm variant dark (`rgba(amber/red, 0.12)` bg, border 0.3).
  - Các `--side-*` trong `.sidebar` → remap theo light/dark; scrollbar (`.side-scroll`, `::-webkit-scrollbar`) đổi màu theo theme.
- Font: body dùng Geist, thêm `.font-mono-tech`-style cho label/metadata (block-label, sources-title, message-meta, doc-tab-meta, doc-stat-label, doc-drawer-kicker, upload-hint) để tạo vibe mono đặc trưng của portfolio; tăng dùng `uppercase + tracking` cho nhãn nhỏ.
- Decoration nhẹ cho đúng vibe portfolio: thêm radial accent-glow mờ sau empty-state (giống blob `#9BCEC1/5`), giữ tối giản, không phá layout.
- Radius/shadow: giữ scale hiện tại (đã gần khớp: 10–24px), chỉ tinh chỉnh shadow composer/drawer theo mode (dark giảm shadow, dùng border).

### 5. `ui/src/components/sidebar/Sidebar.tsx` (sửa nhỏ)
- Thêm `<ThemeToggle />` vào `sidebar-top` (cạnh brand).

## Không đổi
- Không đụng backend, API, logic chat, component chat/citations/drawer.
- Không thêm dependency mới (chỉ Google Fonts qua `<link>`).

## Kiểm chứng
- `cd ui && npm run build` (hoặc `tsc --noEmit`) để đảm bảo không lỗi TS/build.
- Chạy `npm run dev`, mở ở chế độ light và dark, kiểm tra nhanh các vùng: sidebar, chat, composer, citations, warning badge, 2 drawer, doc inspector.
- Xác nhận không regress chức năng (upload/chat vẫn chạy).
