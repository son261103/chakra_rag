## Mục tiêu

Bỏ hoàn toàn embedding local (sentence-transformers/MiniLM chạy trong RAM). Embedding trở thành một **tích hợp dạng integration** y hệt LLM: bảng riêng `embedding_integrations`, cấu hình trên Settings UI (base URL tự điền — dùng được Mistral/OpenAI/anywhere, API key mã hóa DEK/KEK, tên model, **thêm trường Chiều vector (dimension)**).

## A. Backend — xóa local, thay bằng API client

1. **`src/core/embedding.py`** — viết lại, giữ nguyên tên `Embedder` + interface (`embed`/`embed_one`/`dim`, trả `np.float32` đã L2-normalize) để `retrieval.py` + `worker.py` + `chunk_repository.py` **không phải sửa gì**:
   - `__init__(cfg, integration_repo=None)` — bỏ model load.
   - Mỗi lần gọi: resolve tích hợp active (decrypt key bằng `ENCRYPTION_KEY`) → fallback env `cfg.embed_*`; cache theo fingerprint `(base_url, model, api_key)` — pattern giống hệt `RagAgent.resolve_active_llm_config`.
   - Client: `langchain_openai.OpenAIEmbeddings(base_url=..., check_embedding_ctx_length=False)` — reuse `openai` SDK đã có trong deps; `base_url` tự do (Mistral: `https://api.mistral.ai/v1` + `mistral-embed`). **Không gửi tham số `dimensions`** (Mistral không hỗ trợ) — chiều chỉ để validate: vector trả về ≠ dimension khai báo → raise rõ ràng.
   - L2-normalize thủ công bằng numpy (giữ nguyên khế ước `<->` + score `1-d/2` + index HNSW `vector_l2_ops`).
2. **`src/config.py`** — block `Embedding (local)` → `Embedding (API)`: thêm `embed_base_url` (mặc định `https://api.mistral.ai/v1`), `embed_api_key` (`EMBED_API_KEY`), `embed_model` (`mistral-embed`), `embed_dim` (`1024`). Giữ `embed_batch_size`. Cập nhật `.env.example`.
3. **Schema** — file mới `src/storage/schemas/embedding_integrations.py` (mirror `llm_integrations` + `dimension INTEGER NOT NULL`), đăng ký vào `TABLE_SCHEMAS` + `schema.py`.
4. **Repository** — file mới `src/repositories/embedding_integration_repository.py` (mirror `IntegrationRepository` + dimension). Thêm vào `ChunkRepository`: `vector_dimension()` (đọc `atttypmod` cột `chunks.embedding`) và `migrate_dimension(new_dim)` (drop index HNSW → TRUNCATE → `ALTER COLUMN embedding TYPE vector(new)` → tạo lại index).
5. **Service** — file mới `src/service/embedding_integration_service.py`: `ensure_default` seed từ env khi bảng trống (giống LLM), CRUD + activate (mã hóa key), `get_active_info` (+ env fallback), `test_connection` gọi embed "Hi" thật → trả `{ok, model, dimension_thực_tế, latency_ms}` để phát hiện khai sai chiều.
6. **Flow đổi chiều (đã chốt: confirm → reset)**: `activate`/`update` nếu `dimension` khác chiều cột hiện tại và `count_chunks() > 0` → trả **409** `{current_dimension, new_dimension}`; client gửi lại với `force=true` → chạy `migrate_dimension` + `UPDATE files SET status='failed', error='Đổi chiều vector — cần nạp lại'` + notify SSE. `count_chunks()==0` → migrate âm thầm (không mất gì). User tự bấm ↻ từng file để reingest (đúng nguyên tắc no-auto-run).
7. **`src/storage/connection.py`** — `Database(embed_dim=None)`: nếu None thì chạy schema không-chunks trước, đọc `dimension` từ row active (fallback `cfg.embed_dim`), rồi chạy `CHUNKS_SCHEMA.format(dim=...)` — giải quyết vòng lặp "DDL cần dim nhưng dim nằm trong bảng". Test cũ vẫn pass `embed_dim=4` tường minh.
8. **`src/service/container.py`** — wire: resolve dim trước khi tạo `Database` → tạo `EmbeddingIntegrationRepository` + service → `Embedder(cfg, repo)`.
9. **Routes** — file mới `src/api/routes/embedding_integrations.py`, prefix `/embedding-integrations`, 7 endpoints mirror LLM; đăng ký vào `routes/__init__.py` + `app.py`. Response có `dimension`.
10. **`src/observability/logging_setup.py`** — xóa 3 logger `sentence_transformers/transformers/torch`.

## B. UI (`ui/src`)

- `api/types.ts` + `api/client.ts`: types + 7 hàm `*EmbeddingIntegration*` gọi `/api/embedding-integrations`.
- `components/settings/SettingsDrawer.tsx`: thêm **segmented control 2 tab "LLM" | "Embedding"** dưới header; reuse toàn bộ list/modal/form hiện có; form embedding thêm input number "Chiều vector (dimension)"; row hiển thị `model · 1024d`; nút Kiểm tra kết nối gọi test endpoint; bắt 409 → `window.confirm("Đổi chiều sẽ xóa toàn bộ vector cũ, phải bấm ↻ nạp lại từng file. Tiếp tục?")` → retry `force=true`. Tiếng Việt, đúng style conventions hiện có (lucide icons, Tailwind v4, panel).

## C. Dọn dependency

- `pyproject.toml`: bỏ `sentence-transformers` → `uv sync --extra dev` + regenerate `requirements.txt` (`uv pip compile pyproject.toml -o requirements.txt`) — kéo theo torch/transformers/scikit-learn/scipy bay khỏi venv (bớt cả GB). `numpy` giữ lại.
- `.env` của bạn: nhắc bạn tự sửa/xóa dòng `EMBED_MODEL` (file không commit, tôi không đụng).

## D. Tests

- `tests/test_smoke.py`: fixture model thật → **`DeterministicEmbedder` fake** (rng seed theo text, normalize, dim nhỏ) — hết download model, hết cần mạng; assertion `max_score > 0.25` đổi thành assert thứ hạng. `test_service_flows`/`test_service_langsmith`: cập nhật fake theo constructor mới.
- Test mới: repository embedding (CRUD/active/dimension), API routes (container mock), `migrate_dimension` (DB test dim=4 → migrate 8 → insert OK), flow 409-force, `test_embedder_api` (fake OpenAIEmbeddings: normalize + validate dim + env fallback).
- Chạy `uv run ruff check src tests scripts` (gate bắt buộc theo AGENTS.md); **pytest chỉ chạy khi bạn yêu cầu** theo đúng rule no-auto-run của bạn.

## Lưu ý rủi ro

- `MIN_SCORE=0.25` tune theo thang MiniLM — đổi model khác có thể lệch; giữ nguyên, ghi chú trong docs để retune sau (không đổi code).
- Nếu Mistral endpoint của bạn trả shape khác `data[].embedding` → báo lỗi rõ khi test connection; adapter riêng sẽ tính sau (hiện Mistral dùng shape chuẩn OpenAI-compatible nên ổn).
- DB cũ của bạn: vector 384 sẽ bị reset khi bạn kích hoạt config Mistral 1024 → bấm ↻ nạp lại từng file — đúng luồng đã chọn.
